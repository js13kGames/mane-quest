Help Mike the unicorn in this weird 2D ARPG/platformer

## Controls
- mobile/tablet (landscape): tap to move/jump to specific location or to interact with NPC/actions
- desktop: keyboard: arrows or WASD to move, Space to jump, Enter to interact
